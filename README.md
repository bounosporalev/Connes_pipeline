# Algebraic Topology Pipeline for Quantum Networks

An entirely coordinate-free, grid-free topological engine based on Alain Connes' cyclic cohomology to compute topological invariants directly from raw graph connections. 

The pipeline replaces Euclidean geometry with graph geodesics and projects operator variations onto cycle-space Wilson loops to extract quantized plateaus and map Wannier localization obstructions on irregular networks.

### Tested Models
* Disordered flat torus
* Kapit-Mueller model
* Curved, non-bipartite {7,3} hyperbolic Haldane lattice
